# v2.28.1 — Machine Quick Finder

อัปเดตหน้า Admin > เครื่องจักร เพื่อค้นหาเครื่องเร็วขึ้นโดยไม่ต้องเลื่อนยาว

- กรองตามแผนก: ทั้งหมด / MVR / MSR / MVR-LOTUS / IJ / MPR
- ช่องค้นหาเลขเครื่อง ชื่อเครื่อง กลุ่ม และไลน์
- กรอง Criticality A/B/C
- Filter bar แบบ sticky ขณะเลื่อนหน้า
- กลุ่มเครื่องและเครื่องจักรถูกกรองตามแผนกเดียวกัน
- ตัวเลข A/B/C เปลี่ยนตามตัวกรองปัจจุบัน
- เมื่อกดเพิ่มกลุ่ม/เพิ่มเครื่องขณะเลือกแผนก ระบบเตรียมแผนกนั้นให้ในฟอร์ม
- ไม่มีการเปลี่ยนฐานข้อมูล และไม่เปลี่ยนหน้าฝั่งช่าง
