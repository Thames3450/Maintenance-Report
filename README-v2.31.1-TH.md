# v2.31.1 — Mobile Dropdown Bottom Sheet Fix

ปรับ SearchSelect ทุกจุดสำหรับมือถือให้เปิดเป็น Bottom Sheet เต็มพื้นที่แทน Dropdown ลอย

- เลื่อนรายการภายในได้โดยเมนูไม่เด้งปิด
- ล็อกหน้าหลักขณะเลือก ลดปัญหาหน้าจอเลื่อนซ้อน
- Search ไม่ Auto Focus บนมือถือ จึงไม่เด้งคีย์บอร์ดทันที
- มีปุ่มปิดชัดเจน และแตะพื้นหลังเพื่อปิด
- Search Box คงอยู่ด้านบน รายการเลื่อนได้อิสระ
- แสดงจำนวนผลลัพธ์ด้านล่าง
- ใช้กับ อาการเสีย / จุดเสีย / สาเหตุ / วิธีแก้ไข / สถานะ และ SearchSelect อื่นทั้งระบบ
