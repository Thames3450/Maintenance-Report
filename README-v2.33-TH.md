# v2.33.0 — Spare Department History

ปรับหน้า Spare Requests สำหรับช่างให้ดูประวัติอะไหล่ของแผนกตัวเองได้แบบ Read-only

- เพิ่มแท็บ `ของฉัน` และ `ประวัติแผนก`
- ช่างเห็นรายการของทุกคนเฉพาะแผนกตัวเอง
- ดูผู้แจ้ง เครื่อง จำนวน วันที่แจ้ง สถานะ และรูปประกอบได้
- ช่างต่างแผนกมองไม่เห็นกัน
- การแก้ไขสถานะ/รวม Batch/ส่งจัดซื้อยังเป็นสิทธิ์ Admin เท่านั้น
- Purchase Batches ยังไม่เปิดให้ช่างดู
- ฝั่งฐานข้อมูลใช้ RLS บังคับสิทธิ์ ไม่ได้พึ่งแค่การซ่อนหน้าเว็บ
