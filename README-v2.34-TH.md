# v2.34.0 — MPR Supervisor Global Read

เพิ่มบทบาท Supervisor สำหรับหัวหน้า MPR แบบ Read-only ข้ามแผนก

- Login ด้วยรหัสพนักงานเหมือนช่าง
- ดูประวัติงานซ่อมทุกแผนก
- กรองตามแผนก / เครื่อง / ช่าง / วันที่ / สถานะได้
- ดูประวัติความต้องการอะไหล่ทุกแผนกและรูปประกอบได้
- ไม่มีสิทธิ์แก้ไข/ลบรายงาน เปลี่ยนสถานะอะไหล่ สร้าง Batch หรือเข้า System Settings
- Admin ตั้ง Role = Supervisor ได้จากเมนูจัดการผู้ใช้งาน
