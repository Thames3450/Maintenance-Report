# MVR Smart Maintenance v2.35.2

## Spare Request — Save/Upload Fix

แก้ปัญหาหน้าแจ้งอะไหล่ค้างที่ “กำลังบันทึก…” โดยเฉพาะเมื่อแนบรูปจาก iPhone หลายรูป

- บันทึกข้อมูล Spare Request ลงฐานก่อน แล้วแสดงสถานะชัดเจนว่า “บันทึกข้อมูลแล้ว”
- ลดขนาดรูปขนาดใหญ่บนเครื่องผู้ใช้ก่อนอัปโหลดเมื่อเบราว์เซอร์รองรับ
- อัปโหลดรูปหลายช่องพร้อมกันแทนการอัปโหลดทีละรูป
- บันทึกข้อมูลรูปลงฐานทีละรูปทันทีหลังอัปโหลดสำเร็จ ลดปัญหาไฟล์ค้างโดยไม่มี record
- ถ้ารูปบางรูปอัปโหลดไม่สำเร็จ รายการอะไหล่ยังคงถูกบันทึก และผู้ใช้สามารถเข้าแก้ไขเพื่อแนบรูปใหม่ได้
- การเปลี่ยนรูปในหน้าแก้ไขจะลบรูปเดิมเฉพาะเมื่อรูปใหม่ของช่องนั้นอัปโหลดสำเร็จ
- แสดงความคืบหน้า เช่น “บันทึกข้อมูลแล้ว · กำลังอัปโหลดรูป 2/3…”

ไม่ต้องรัน SQL เพิ่มสำหรับเวอร์ชันนี้
