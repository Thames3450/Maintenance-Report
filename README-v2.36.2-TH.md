# MVR Smart Maintenance v2.36.2

ปรับ Spare Requests ให้เปลี่ยนสถานะโดยไม่รีเฟรชทั้งหน้า

- ปุ่ม รับตรวจ / ข้อมูลครบ / ติดตามต่อ / ปิดรายการ อัปเดตการ์ดเฉพาะรายการทันที
- ไม่ขึ้นหน้า Loading ทั้งหน้าหลังเปลี่ยนสถานะ
- งานสร้าง Batch / ส่งจัดซื้อ / บันทึก / แก้ไข / ลบ ใช้ Silent Refresh เพื่อลดการกระพริบของหน้า
- การกดรีเฟรชเองยังคงโหลดข้อมูลใหม่ตามปกติ
