# v2.37.1 — IJ Material Leak Required Mold Alert

- ใช้เฉพาะเครื่อง Injection ในแผนก IJ
- เมื่อเลือก Material Leak ระบบแจ้งเตือนทันทีว่าต้องกรอก รุ่นโมล / Mold No.
- ระบุชัดเจนว่าเป็นรหัส/รุ่นของโมลที่ติดตั้งบนเครื่อง ไม่ใช่รุ่นเครื่อง Injection
- ช่อง Mold No. แสดงทันทีในขั้นเลือกอาการและบังคับกรอกก่อนผ่านขั้นตอน
- ฝั่งฐานข้อมูลยังตรวจซ้ำ หากไม่มี Mold Model จะไม่รับรายงานและคืนข้อความแจ้งเตือนที่ชัดเจน
